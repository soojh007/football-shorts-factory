Privacy Policy

Last updated: 21 November 2026

Football Shorts Factory (also named “Football Shorts” on the Google consent screen) is operated by the maintainer of the soojh007/football-shorts-factory repository. It creates football prediction videos and, when authorized, uploads them privately to the connected YouTube channel. Contact: predictionleaguesite@gmail.com.

Information the application uses

  • YouTube authorization: Google OAuth access and refresh tokens, the authorized channel’s ID and title, and upload responses including video IDs and processing information. The requested permissions are youtube.upload to upload videos and youtube.readonly to identify and verify the intended channel. The current workflow does not read private viewing history or subscriptions.
  • Production information: selected fixture IDs, football statistics, public player/media information, scripts, narration, videos and upload metadata.
  • GitHub connection: a GitHub personal access token used to verify repository access, start workflows and check their status.
  • Website access: GitHub Pages and other providers may process technical request information such as IP addresses under their own privacy policies. This website does not add its own analytics or advertising trackers.

Purpose and sharing

YouTube data is used only to connect the intended channel, upload the selected video, check upload status and prevent duplicate uploads. Google receives the video, title, description and other upload settings. The hosted workflow requests private uploads; the channel owner decides whether to publish later through YouTube Studio.

GitHub hosts the public website and runs authorized production jobs. OpenAI processes football evidence and scripts for research and narration, and generated audio for captions. Sportmonks supplies football data. Public media sources supply licensed imagery. YouTube OAuth credentials and private channel/upload records are not included in prompts sent to OpenAI and are not used to train AI models by this application. The public match schedule may include competition names, team names, fixture IDs and kickoff times available through the operator’s subscription.

We do not sell Google user data or use it for advertising. Access is limited to the operator and service providers needed for these functions, except where disclosure is required by law or authorized by the account owner.

Storage and security

YouTube credentials are stored in restricted local files during local use and in GitHub Actions repository secrets for hosted use. Workflow runners receive the credentials while executing authorized jobs. Credentials, videos and private production files are not committed to the public repository or published on this website.

The GitHub token stays in browser memory while connected. If you choose “Remember encrypted token on this device,” browser storage holds password-encrypted ciphertext using AES-256-GCM and PBKDF2-SHA256. The unlock password is not saved. The connection locks after inactivity or page closure. “Forget saved token” removes the saved ciphertext. Browser extensions or malicious software on an unlocked device can still expose information; encryption is not an absolute guarantee.

Duplicate-prevention upload records are encrypted before storage as GitHub Actions artifacts, with a configured retention of 90 days. Local production files and credentials remain until the operator deletes them; repository secrets remain until replaced or deleted. Uploaded videos remain on YouTube until the channel owner removes them. Provider logs, backups and retention are governed by the relevant provider.

Your choices and deletion

You can revoke Google access at Google Account connections. Revocation stops future authorized access but does not delete existing YouTube videos. Remove videos through YouTube Studio. To remove application-held data, delete the local credentials and generated files, remove the repository’s YouTube OAuth secret and associated encrypted workflow artifacts, or contact the operator for assistance. Duplicate-prevention records should be reconciled with YouTube Studio before any new upload.

Lock or forget the GitHub connection on this website and revoke the GitHub token in GitHub settings when no longer needed. You may request access, correction or deletion of information held by the operator at the contact email above. Do not include passwords, tokens or verification codes in your request.

Google and YouTube policies

Football Shorts Factory’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. The application uses YouTube API Services. See the Google Privacy Policy, GitHub Privacy Statement and OpenAI Privacy Policy for provider practices.
